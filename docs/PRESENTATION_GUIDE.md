# Guided presentation

## Starting and controlling

Select **Start Presentation** in the desktop presenter panel or **Demo Controls → Start presentation**. The overlay shows the current step, presenter note and route. Use Previous/Next or the arrow keys where available. Steps 9 and 12 open their service and phone dialogs automatically; close the active dialog before continuing. Select Exit, or press Escape while no dialog is open, to leave presentation mode.

The 16 steps move through:

1. Alex's next action
2. zone selection
3. zone-aware table choice
4. courtesy transport
5. arrival and check-in
6. usual food order
7. controlled group round
8. Screen 7 coordination
9. Table Service
10. member rewards
11. customer memory
12. telephone receptionist
13. Northside UFC context
14. UFC-specific operations
15. Hinterland accessibility
16. bottle-shop collection

The last four steps intentionally load different synthetic scenarios to prove that products, zones, layouts, screens, transport and service conditions are venue-local.

## Presenter notes

- Keep the permanent unofficial/synthetic disclaimer visible before discussing features.
- Describe screen requests as venue-controlled requests, not customer control of a television.
- Describe alcohol actions as requests for human review, not approved supply.
- Describe the receptionist as disclosed automation using deterministic scripted paths.
- Use customer memory and campaign explanations to show control and excluded inputs.
- End on collection staff confirmation, then reiterate that every workflow is local and non-operational.

## Public QR

The wide-screen panel renders `https://wowcorey.github.io/star-local-concept/` as both an SVG QR and visible text. The QR is generated locally at runtime and contains no tracking token or customer identifier.

## Recovery

Escape exits presentation mode when no step dialog is open. Demo Controls can reload any scenario or reset the full app. Previous and Next reapply each step's complete deterministic setup, including venue switches. The presentation step itself is persisted safely but an open overlay is never restored after a hard reset.
